# 04 — Brand Asset Checklist

**CheeseShop TECH client onboarding · for the design team**

Everything on this list feeds your Brand Kit — the single source of truth that paints every page, proposal, and campaign asset in the platform. Original files beat exports: send us the real thing.

## Logo package

- [ ] Primary logo — **SVG or AI** (vector required) + transparent PNG (≥1000px wide)
- [ ] Wordmark / horizontal variant (vector)
- [ ] Seal, crest, or secondary mark if one exists (vector)
- [ ] Favicon or app-icon version (square, vector or ≥512px PNG)
- [ ] Any clear-space / minimum-size rules

## Color

- [ ] Primary brand color — **hex** (plus PMS if you print)
- [ ] Accent color(s) — hex
- [ ] Secondary palette and neutrals, with any usage ratios or rules
- [ ] Colors that must never be used together

## Typography

- [ ] Display / headline font — family name + **license status** (we can only use licensed fonts)
- [ ] Body / UI font — family name + license status
- [ ] Web-font files or foundry links if self-hosted
- [ ] Fallback preferences if a font can't be embedded

## Brand guide

- [ ] Brand guidelines document — **PDF** (any age; we extract what's current)
- [ ] Packaging dielines or label artwork if relevant (PDF/AI)

## Photography & imagery

- [ ] Product packshots — original resolution (**≥3000px** long edge), JPG/PNG/TIFF
- [ ] Named `<itemnumber>_<descriptor>.jpg` when the photo shows a specific product (item numbers = file 01)
- [ ] Lifestyle / environment photography
- [ ] Production / provenance photography (facility, process, people, place)
- [ ] Food-styling / recipe photography
- [ ] Any patterns, textures, or illustrations that belong to the brand

Every image gets tagged into the platform's usage taxonomy on our side (Product Catalog, Hero, Story block, Lifestyle, Food styling, Social, Press/PR, Event, Brand asset, Email/Campaign, Print/Sell-sheet, Web/Marketing) — if you already know an image's job, note it in the filename or a manifest and we'll honor it.

## Video (if any)

- [ ] Brand or product video — original files or a link (we handle hosting)

## Delivery

One folder (Drive/Dropbox/WeTransfer link is fine), subfolders per section above. No files embedded in Word docs or PDFs — always the originals.
