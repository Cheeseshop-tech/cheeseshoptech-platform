Asiago Shelf-Talker — Composition Studio

Condensed single-size format — 2.5″ × 3.5″, no photo — for tight shelf/case real estate, distinct from the existing 3″×4″ / 4″×5″ case signs. Three fresh layouts (G, H, I, continuing the lettering from the case-sign composition round) applied to the four Asiago signs, using the copy just rewritten from the Consorzio Tutela Formaggio Asiago's own consumer booklet. Content per card: name · Italian name · flavor line · one sensory "recognize it" cue (new — see the note below) · age chip · DOP badge (house stand-in, same as the case signs) · QR. DOP badge and QR are placeholders here — real art/codes render once a layout is picked and the template is built.

G Green cap — same logic as the recommended case-sign layout

A full-bleed Forest Green header with the name reversed out reads fastest at a glance — the actual job for a shelf talker seen from a few feet away, walking past. Recommended default.
