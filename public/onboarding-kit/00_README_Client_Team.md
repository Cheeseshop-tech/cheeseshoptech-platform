## Ground rules (they matter)

1. **Item numbers are sacred.** The item number in file 01 is the key that links inventory, photos, orders, quotes, and campaigns. Same code, everywhere, exactly.
2. **Native formats only.** Spreadsheets as .xlsx (or Google Sheets share) — never PDF price lists or scans. Logos as vector (SVG/AI). Photos at original resolution.
3. **Don't restructure the templates.** Headers stay as they are; one row per item; no merged cells; no totals rows. If your system exports differently, send the raw export too — we adapt.
4. **Example rows** (gray italic) show what good looks like — delete them before returning the file.
5. **Partial beats perfect.** Send what you have as sections finish; don't hold everything for the last photo.
